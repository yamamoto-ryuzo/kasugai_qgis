description=Localhost-only remote control driver for QGIS (token-authenticated MCP/REST/file API for local AI tools) plus a built-in AI assistant panel for OpenAI-compatible APIs and a hot-reload watcher for plugin development
about=Exposes QGIS internals to local clients via commands.jsonl/results.jsonl, REST /api/* and MCP Streamable HTTP /mcp on 127.0.0.1 only. All channels require a per-session token stored in user-only files. Disabled by default; enable via the Plugins > QGIS Live Driver menu or WEBENGINE_LIVE_DIR env. pyeval executes arbitrary Python inside QGIS — the trust boundary is the local user account. The AI アシスタント dock (Plugins > QGIS Live Driver > AI アシスタント) connects an OpenAI-compatible, Gemini or GitHub Copilot API and lets the model run the driver's tools via function calling. The ホットリロード submenu (Plugins > QGIS Live Driver > ホットリロード) reloads a chosen plugin in-place (sys.modules cleanup + reloadPlugin + dialog reopen) for development without restarting QGIS. The Deploy Mode dialog (Plugins > QGIS Live Driver > Deploy Mode) switches the deploy mode between development (junction = repository sources) and usage (restored parked copy) via the harness deploy script. The shared GeoSuite toolbar hosts all managed-plugin toolbar items; the driver adds an always-visible mode badge (Development/Usage) at its head — click it to open the Deploy Mode dialog.
