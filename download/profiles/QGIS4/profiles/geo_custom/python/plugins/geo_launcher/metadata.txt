about[en]=Detects, installs (downloads and runs the setup), uninstalls, and opens the GUI window of kasugai_qgis (https://github.com/yamamoto-ryuzo/kasugai_qgis), a Rust/Axum QGIS launcher. The launcher itself exits automatically once QGIS starts, so this plugin does not run or maintain its API server. It also shows whether the current QGIS instance was started via the launcher (PORTAL_USERROLE).
