5. XYZ タブ — タイル焼き付け・ベースマップ

geo_webview ドキュメント / 使い方

使い方

Vector → XYZ タイル焼き付け（自動）

  • XYZ tiles (faster display) チェック＋ Zoom zmin/zmax — .kasc エクスポート時に、大規模・複雑スタイルでベクター描画が重いレイヤを QGIS レンダラで XYZ タイル画像へ焼き付け、<slug>_xyz/（{z}/{x}/{y}.png + index.html）を canvas_data/ へ置いて xyz: 行で出力
  • 注意: Canvas 側フィルタ（where=/属性フィルタ）は焼き付け画像に反映されない （焼き付け時点の地図に固定される）

Basemap Groups

  • 「背景図」「ベースマップ」「basemap」既定名に加えて、ベースマップ候補として扱う レイヤツリーのグループ名をカンマ区切りで追加する。該当グループ内の XYZ は位置・表示状態に 関わらず base: 行として出力される

Standalone XYZ export（独立出力）

  • Export XYZ — レイヤパネルで選択中のレイヤを、上記 Zoom 設定で .kasc とは別経路に <出力先>/xyz_tiles/<layer>/ へ焼き付ける （空タイルはスキップ、各レイヤに index.html ビューア付き。 /export-data/xyz_tiles/<slug>/index.html でブラウザ確認も可）
  • Add baked tiles to the project as XYZ layers — 焼き付け後にタイルツリーを type=xyz（file:// テンプレート）のラスタレイヤとしてプロジェクトへ追加（既定 ON）
  • 📁 — xyz_tiles/ ルートをエクスプローラで開く

設定・ツール仕様

XYZ タブは3つのグループで構成される:

Vector → XYZ tile bake（自動焼き付け）

  • XYZ tiles (faster display) チェック（QSettings kasugai_xyz_tiles、既定 ON）＋ Zoom zmin/zmax （QSettings kasugai_xyz_zmin/kasugai_xyz_zmax、既定 1-15）: .kasc エクスポート時に、大規模・複雑スタイルでベクター描画が重いレイヤを QGIS レンダラで XYZ タイル画像へ焼き付け、<slug>_xyz/ （{z}/{x}/{y}.png + index.html）を canvas_data/ へ置いて xyz: 行で出す
  • レイヤ別オーバーライド: レイヤ customProperty kasugai_render （xyz=必ず焼き付け / vector=焼き付けない / auto・空=自動判定）
  • ズーム範囲はパネル設定にレイヤの縮尺連動（minScale/maxScale）を重ね合わせ、 タイル数上限でクランプする
  • 注意: Canvas 側フィルタ（where=/属性フィルタ）は焼き付け画像に 反映されない（焼き付け時点の地図に固定される）

Basemap Groups

  • lineEdit_xyz_basemap_groups（QSettings kasugai_basemap_groups、カンマ区切り）— 「背景図」「ベースマップ」 「basemap」既定名に加えて、ベースマップ候補として扱うレイヤツリーの グループ名を追加する。該当グループ内の XYZ は位置・表示状態に関わらず base: 行として出力される（§1 .kasc 行の生成規則）

Standalone XYZ export（手動焼き付け）

  • Export XYZ — レイヤパネルで選択中のレイヤを、上記 Zoom 設定で .kasc とは別経路に <出力先>/xyz_tiles/<layer>/ へ焼き付ける（空タイルはスキップ、各レイヤに index.html ビューア付き。 /export-data/xyz_tiles/<slug>/index.html でブラウザ確認も可）
  • Add baked tiles to the project as XYZ layers — 焼き付け後に タイルツリーを type=xyz（file:// テンプレート）のラスタレイヤとして プロジェクトへ追加し、キャンバスで結果を確認する（既定 ON）
  • 📁 — xyz_tiles/ ルートをエクスプローラで開く
