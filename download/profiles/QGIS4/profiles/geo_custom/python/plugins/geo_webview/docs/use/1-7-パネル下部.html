7. パネル下部（タブ外） — External Control・設定

geo_webview ドキュメント / 使い方

使い方

External Control（外部制御）

  • パネル下部の External Control チェックを ON にすると、外部から受信した URL を 自動適用して QGIS をナビゲートする
  • パースされるパラメータ（x/y/scale/crs/ rotation/theme）は 6. Other タブのパーマリンク形式に準じる
  • パネル起動時に既に受信済みの URL がある場合は自動ナビゲートを実行（設定に依存）
  • 自動ナビゲートは UX を上書きするため、明確な ON/OFF トグルを持つ

設定ダイアログ（歯車ボタン）

  • パネル右下の歯車ボタンで開く設定画面。KASUGAI Canvas インストール先・ホスト版チャンネル・ Basemap Groups・Vector Export Format（＋Visible data only）を管理
  • いずれもパネル側の同名コントロールと同じ QSettings を読み書きする

設定・ツール仕様

External Control（外部制御）

  • 機能: パネル下部の External Control チェック （checkBox_external_control）が有効なら、外部から受信した URL を 自動適用して QGIS をナビゲートする。
  • パースされるパラメータ（x/y/scale/crs/ rotation/theme）は §6 のパーマリンク形式に準じる。
  • 動作:
    • 受信 URL をパースして navigate_from_http ルートを使い QGIS の表示を更新する。
    • パネル起動時に既に受信済みの URL がある場合は自動ナビゲートを実行（設定に依存）。
  • セキュリティ: 自動ナビゲートは UX を上書きするため、明確な ON/OFF トグルを持ち、ログに受信元・実行時刻を記録することを推奨。

設定ダイアログ（歯車ボタン）

  • settings_dialog.py — パネル右下の歯車ボタンで開く設定画面。 KASUGAI Canvas インストール先・ホスト版チャンネル （kasugai_hosted_channel/kasugai_hosted_value）・ Basemap Groups（kasugai_basemap_groups）・Vector Export Format （kasugai_vector_format＋Visible data only）を管理し、 いずれもパネル側の同名コントロールと同じ QSettings を読み書きする。
