4. Filter タブ — サイト共通フィルタ

geo_webview ドキュメント / 使い方

使い方

Filter タブは、site（レイヤツリーのグループ名・Layers タブの site= 解決規則と同一ロジック、 グループ無しは「その他」）内の全ベクターレイヤへ共通の属性フィルタ（subset string）を 一括適用します。地図表示とエクスポートデータ（subsetString は where= へ 引き継がれる）の両方に反映されます。

条件選択（Site・Field・値）

  • Site: — site 名の一覧を選択（タブを開くたび最新化）
  • Field: — メンバー全レイヤに共通する属性フィールドのみ列挙 （全レイヤで数値型のものは (num) 付記）。共通フィールドが無ければ No common field と表示
  • 条件行 — フィールド型で自動切替。数値型なら演算子 = != < <= > >=＋数値入力、文字列型なら = !=＋値コンボ（既存値の列挙）

複数選択・自動適用

  • Multiple selection — IN/NOT IN＋値チェックリスト （全選択/全解除ボタン付き）の複数値モードへ切替
  • 自動適用 — site+field+値が揃った時点で即適用（適用ボタン不要。 テキスト入力は 350ms デバウンス）
  • Clear — サイト内全レイヤの subset string を解除

設定・ツール仕様

Filter タブ（panel.py: _init_kasugai_filter_ui）は、 site（レイヤツリーのグループ名・Layers タブの site= 解決規則と同一ロジック、 グループ無しは「その他」）内の全ベクターレイヤへ共通の属性フィルタ （subset string）を一括適用する。地図表示とエクスポートデータ （subsetString は where= へ引き継がれる、§1 .kasc 行の生成規則）の 両方に反映される。

  • Site: コンボ — site 名の一覧（Layers タブと同じ kasugai_site/グループ自動付与の規則で集約）。タブを開くたび最新化
  • Field: コンボ — メンバー全レイヤに共通する属性 フィールドのみ列挙（全レイヤで数値型のものは (num) 付記）。 共通フィールドが無ければ No common field と表示
  • 条件行（自動切替） — フィールドが数値型なら演算子 = != < <= > >=＋数値入力、文字列型なら = !=＋ 値コンボ（既存値の列挙）。Multiple selection チェックで IN/NOT IN＋値チェックリスト（全選択/全解除ボタン付き） の複数値モードへ切替
  • 自動適用 — site+field+値（複数選択時はチェック1件以上）が 揃った時点で即適用（適用ボタン不要。テキスト入力は 350ms デバウンス）。 値が0件の IN は常偽式 1=0（全除外）、NOT IN の0件はフィルタ解除として扱う。未完成の選択では誤適用しない
  • Clear — サイト内全レイヤの subset string を解除
  • エクスポート連携 — 選択状態は kasugai_export.set_filter_panel_state() へ随時同期され、 plugin: custom-layer 行の filter_* オプションとして 出力（Canvas 側「フィルタ」タブの初期選択。§3 参照）
