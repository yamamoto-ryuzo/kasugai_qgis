3. Layers タブ — カスタムレイヤタブとレイヤ別オプション

geo_webview ドキュメント / 使い方

使い方

Layers タブは、レイヤごとの .kasc オプションを設定します。値はレイヤ customProperty へ保存され、エクスポート時にレイヤ行の | key=value として出力されます（グレー表示=自動値、空欄に戻すと自動値へ復帰）。

Custom layers tab（site= 自動付与）

  • Custom layers tab チェック — ON でレイヤツリーのグループ名を site=<グループ階層>（例 site=A工区、入れ子は 工事/A工区）として グループ内全レイヤへ自動付与し、Canvas 側に custom-layer タブ（表示名「レイヤ」）を出す
  • Canvas 側ではグループ一括 on/off と、メンバー凡例（QML 分類）の表示・シンボル別 on/off が可能 （point/line/polygon 等の種別違いをまとめて制御）
  • グループ無しレイヤは site= なしで出力され、custom-layer タブの「その他」へ集約（標準レイヤタブには残る）

レイヤ別オプション（site/order/list/opts）

  • レイヤツリー一覧 — ツリー順のレイヤ行＋4列のオプション
  • EDIT/VIEW 切替 — EDIT=オプション編集テーブル / VIEW=出力結果表示と ▲▼ による order 調整
  • Refresh — レイヤツリーを再読み込み
列効果
sitesite=<箇所名>（-/空=強制未割当。空欄＋チェックONでグループ名を自動付与）
orderorder=<数値>（同一 site 内の順序。小さいほど最前面。VIEW モードの ▲▼ で設定）
listlist=off（レイヤ一覧から非表示・標準/カスタムとも。地図は描画）
opts任意の key=value を空白/パイプ区切りで追加（例 opacity=0.5 heat=on）。legend_order=asc|desc|reverse|ラベル列挙 でカスタムタブの凡例順を変更可

設定・ツール仕様

Layers タブは、レイヤごとの .kasc オプションを 設定できる。値はレイヤ customProperty へ保存され、エクスポート時に レイヤ行の | key=value として出力される （グレー表示=自動値、空欄に戻すと自動値へ復帰）。

UI: Custom layers tab チェック＋レイヤツリー一覧 （treeWidget_kasugai_layers、ツリー順のレイヤ行＋4列のオプション）＋ EDIT/VIEW 切替ボタン（EDIT=オプション編集テーブル / VIEW=出力結果表示と ▲▼ による order 調整）＋Refresh。

列customProperty.kasc 出力
sitekasugai_sitesite=<箇所名>（-/空=強制未割当。空欄＋チェックONでグループ名を自動付与）
orderkasugai_orderorder=<数値>（同一 site 内の順序。小さいほど最前面。VIEW モードの ▲▼ ボタンで設定（EDIT の列は無し））
listkasugai_listlist=off（レイヤ一覧から非表示・標準/カスタムとも。地図は描画）
optskasugai_opts任意の key=value を空白/パイプ区切りで追加（例 opacity=0.5 heat=on）。legend_order=asc|desc|reverse|ラベル列挙 でカスタムタブの凡例順を変更可

Custom layers tab チェック（QSettings kasugai_site_control、既定 OFF）を ON にすると、 レイヤツリーのグループ名を site=<グループ階層> （例 site=A工区、入れ子は 工事/A工区）として グループ内全レイヤへ自動付与する。site= 付きレイヤが 1件でも出力されれば assets/custom-layer.js を canvas_data/ へ複製して plugin: custom-layer | name=レイヤ | url=canvas_data/custom-layer.js | before=layers-panel 行を書く（チェックOFFでも customProperty 指定の site= だけは 有効かつプラグイン行が出る）。

  • Canvas 側では site= は custom-layer タブ （表示名「レイヤ」）専用の集約キーで、標準レイヤタブには 全レイヤが従来通り表示される（標準一覧から隠すには list=off。タブ名が重複するため組み込み側は 「システムレイヤ」に改称される）。custom-layer タブでは グループごとの一括 on/off と、メンバーの凡例（QML 分類） の表示・シンボル別 on/off ができる。point/line/polygon 等の 種別違いをまとめて制御できる
  • グループ無しレイヤは site= なしで出力され、 custom-layer タブの「その他」に集約されて一括 on/off （標準レイヤタブには残る）。ベースマップグループは対象外
  • url= はプロジェクト相対のため CDN/静的ホスティング・全エンジンでそのまま動作する。 プラグインJSの正本は Canvas web/cesium/PLUGIN/custom-layer/plugin.js
  • plugin: 行には Filter タブの選択状態が filter_site=/filter_field=/filter_multi/ filter_op=/filter_value=/filter_values= として付記され、Canvas 側「フィルタ」タブの初期選択になる（§4）

切替経路:

  • パネル Layers タブの Custom layers tab チェック — 永続
  • 設定ダイアログの同名チェック — 永続
  • bridge kasugaiExport(site_control=True|False) — 呼出しのみ上書き
  • export_kasugai_project(site_control=…) — 呼出しのみ上書き
