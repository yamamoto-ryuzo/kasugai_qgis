6. Other タブ — テーマ・パーマリンク・共有

geo_webview ドキュメント / 使い方

使い方

テーマ (Theme)

  • テーマ選択コンボ — ナビゲーション時に適用するマップテーマを選ぶ （「-- No Theme (Position Only) --」含む）
  • Save Theme — 現在のレイヤ可視性・スタイルを新規マップテーマとして保存
  • プロジェクト自体の状態は変更しない。未存在のテーマ名は No Theme（位置のみ適用）へフォールバック

パーマリンク（Permalink）

  • Generate Permalink — 現在表示（中心座標、scale、rotation、theme）を /qgis-map パスの HTTP パーマリンクとして生成・表示。URLCopy でコピー
  • Navigate — 貼り付けたパーマリンクへ QGIS をナビゲートする
  • 例: http://localhost:8089/qgis-map?x=139.01234&y=35.12345&scale=1000.0&rotation=0.00

共有（Share / Presentation）

  • Presentation Share — QGIS キャンバスをミラーする /present ページを ブラウザで開き、URL をクリップボードへコピー（LAN IP 優先表示）
  • 受領パーマリンク履歴コンボ（最新10件）— 選択するとナビゲート欄へコピー
  • MAC address authentication チェック＋許可 MAC アドレス欄（カンマ区切り、 空=全拒否）— 登録クライアントのみ HTTP サーバへアクセス可

設定・ツール仕様

テーマ (Theme) グループ

  • テーマ選択コンボ（comboBox_themes、「-- No Theme (Position Only) --」 含む）— ナビゲーション時に適用するマップテーマを選ぶ
  • Save Theme — 現在のレイヤ可視性・スタイルを新規マップテーマとして保存
  • theme パラメータに指定されたマップテーマをナビゲーション時に適用する。 プロジェクト自体の状態を変更しない
  • theme 値はプロジェクト内の既存マップテーマ名のみサポート。未存在の 場合は No Theme（位置のみ適用）へフォールバック
  • スタイルのエクスポートでは QGIS バージョン差に備えて exportNamedStyle 等の呼び出しにフォールバックを用意

パーマリンク（Permalink）グループ

  • Generate Permalink — 現在表示（中心座標、scale、rotation、theme） を /qgis-map パスの HTTP パーマリンクとして生成・表示。 URLCopy でコピー。クリップボードボタンでコピー/貼り付けも可
  • Navigate — 貼り付けたパーマリンクへ QGIS をナビゲートする
  • /qgis-map は HTML を返さず、受領記録・External Control ナビゲートの URL パスとして使う（v3.24.0 でプラグイン内蔵ビューアは廃止）

パーマリンク形式とパラメータ（基本・推奨）:

  • x : 経度（または投影座標系の X）
  • y : 緯度（または投影座標系の Y）
  • scale : QGIS の scale（例: 1000.0）
  • crs : 省略時は EPSG:4326 として解釈。
  • rotation : 表示の回転（度）
  • theme : マップテーマ名（存在する場合に適用する）

例:

http://localhost:8089/qgis-map?x=139.01234&y=35.12345&scale=1000.0&rotation=0.00

短縮形式（プレゼン資料向け）:

  • 小数切り捨て等で x=139&y=35&scale=1000.0 のように短くできる。

変換ルール:

  • scale 指定があれば優先して適用。
  • zoom は内部推定（Web マップ用の推定）で用いるが、基本は scale を優先。

共有（Share / Presentation）グループ

panel.py が groupBox_sharing として動的追加する （.ui 上は tab_share コンテナに挿入）:

  • Presentation Share — QGIS キャンバスをミラーする /present ページをブラウザで開き、URL をクリップボードへコピー （LAN IP 優先表示、§1 サーバグループ）
  • 受領パーマリンク履歴コンボ（comboBox_received、最新10件）— 選択するとナビゲート欄へコピー。履歴本体は GET /received（仕様書「HTTP API リファレンス」）
  • MAC address authentication チェック＋許可 MAC アドレス欄 （カンマ区切り、空=全拒否）— 登録クライアントのみ HTTP サーバへアクセス可

レンダリング（/screenshot）とパフォーマンス

契約（contract）:

  • 入力: w/h（または width/height）。省略時はキャンバスサイズ、上限 4096px。
  • 出力: 現在のキャンバス表示と同等の PNG（回転・縮尺・表示中レイヤを反映）。
  • 応答ヘッダ X-Map-Extent: 実際に setExtent した範囲（キャンバスCRS、 xmin,ymin,xmax,ymax）。X-Map-Corners: 画像の左上/右上/左下の実座標 （x,yを6値連結。回転時も画像の写る位置を正確に示す）。

視聴者ズーム（クライアント単位・ステートレス）:

  • extent=xmin,ymin,xmax,ymax — setExtent リテラル値（直前の X-Map-Extent で同一描画を再現する用途）。
  • screen=xmin,ymin,xmax,ymax — 画面上に見せたい領域。回転時は 逆回転した外接矩形へ内部変換して描画（回転0では extent と同義）。
  • bbox=cx,cy,fw,fh — ベース画像（既定=現在のキャンバス描画）に対する 割合座標で中心(cx,cy)・表示幅高(fw,fh、0..1)を指定して部分描画。 base=<extent>+bw/bh でベース画像を差し替え、ズーム表示を さらに拡大・移動する継続操作ができる（中心計算は mapToPixel 経由で 回転に対応）。
  • rot=<deg> — 描画回転の明示指定（rot=0 で北向き描画）。
  • /present は同梱OpenLayers(vendor/ol)ページ。描画は rot=0 の 北向きレンダリングを ImageStatic で配置し、キャンバス回転は /present/state 経由でビュー回転として再現するため、全ジェスチャが 回転座標系で整合する（再描画は moveend 時のみ要求）。

実装:

  • キャンバスの QgsMapSettings を複製し QgsMapRendererParallelJob で描画する （server_manager._render_map_settings）。GUI スレッドをブロックせず、 HTTP ワーカースレッドから呼べる。
  • 複数の QgsMapRendererParallelJob 同時実行は QGIS クラッシュを招くため _render_lock で直列化する。30秒でタイムアウト（ジョブを cancel）。

性能上の注意:

  • 大きな出力サイズはメモリと CPU を要するため 4096px でクランプする。
