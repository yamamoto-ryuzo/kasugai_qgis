about[en] = geo_webview makes KASUGAI Canvas the persistent live viewer of the open QGIS project (primary role since v4.30.0). `GET /live/kasc` generates the `.kasc` on demand (no export files) and feeds a live session to an external browser via the "Open Canvas Live View" action or the `liveView` bridge (full WebGL/Cesium; embedded WebGL is unavailable under QGIS 4.x, so the view is external-only), with two-way sync of edits, selection and camera. Canvas is therefore not only the web-distribution player for QGIS but also the fast main viewer for heavy content such as 3D Tiles — a two-window workflow where QGIS stays the editing/authoring environment and Canvas does the viewing (embedded WebGL is unavailable under QGIS 4.x, so the 3D path uses the external browser). The legacy capability remains: exporting the project as a `.kasc`+`canvas_data/` package playable on the Canvas multi-engines from static hosting (panel `Export`/`▶ Open`, `/kasugai`, bridge `kasugaiExport`). The embedded HTTP server also provides `/export-data/` delivery, `/present`/`/screenshot` canvas sharing and permalink reception. See README.md and docs/ for usage details and deployment scenarios.
