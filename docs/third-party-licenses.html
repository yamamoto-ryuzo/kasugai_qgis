注意点:

  • GPL コンポーネント（本体含む）は商用利用自体は可能ですが、再配布時にソース提供・ライセンス表示が必須です。プロプライエタリな製品として販売したい場合は GPL 部分を閉じられないため実質不可です（本リポジトリ自体が GPL-3.0 のため、この点は全体に適用されます）。
  • 同梱プラグインは Python ソースのまま配布されるため、GPL のソース提供要件は自動的に満たされます。
  • WinFsp は GPLv3 + FLOSS 特例のデュアル構成です。利用者が個別にインストールする場合は商用利用でも無料です。FLOSS ソフトウェア（GPL 等）であれば無改変のインストーラを同梱配布することも特例で許容されます（著作権表示 + リポジトリリンクの条件付き）。有料の商用ライセンス（組織 $6,000/3年、個人 $2,400/3年）が必要になるのは、クローズドソース製品に WinFsp を組み込んで配布する場合だけです。
    ※ クローズドソース製品 = ソースコードを公開せず、コンパイル済み実行ファイルのみを配布するプロプライエタリなソフトウェア製品（例: Microsoft Office 等）。kasugai_qgis は GPL-3.0 でソース公開済みのオープンソース（FLOSS）なので該当しません。
